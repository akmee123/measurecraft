Workflow: Import drawing → Calibrate scale → Measure in order below → Review Live Quantities → Export BOQ.

📐 Recommended measurement order
  1. Columns — measure all columns first (locations & sizes stored).
  2. Walls — measure walls; column overlaps are auto-deducted using each wall’s own thickness.
  3. Openings — Deduct Wall/Opening; system uses the parent wall thickness (e.g. 100 mm vs 225 mm), never a fixed global value.
  4. Slabs — snap to wall center, edge, or corner; overlaps deduct automatically where applicable.
Tip: hold Alt while clicking to place a point without object snap. Live Quantities shows Gross · Deduction · Net per element.
